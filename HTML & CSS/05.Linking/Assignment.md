### Question 1  
You are creating the homepage of an online platform called “SkillForge Academy”.  
a) Write a paragraph that contains the academy name.  
b) Make the academy name a link that goes to `https://skillforge.academy` and opens in a new tab.  
c) Make the link text bold and add a tooltip that says “Official website of SkillForge Academy”.

### Question 3  
Create two different types of links.  
a) Create an external link to `https://learninghub.org` that opens in a new tab. The link text should be “Visit Learning Hub”.

c) Emphasize the word “External” in the first link text.
